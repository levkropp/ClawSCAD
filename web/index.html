The Workbench isn't part of the web port.

This is the Make view, self-hosted. Four things live in the desktop app and have no browser equivalent, so rather than stub them they are simply absent:

  • The 3D viewport — three.js rendering a mesh loaded from local disk.
  • The terminal — a live Claude Code session over node-pty. This is why Make it cannot hand a brief to Claude from here.
  • OpenSCAD rendering — a local openscad process per change.
  • The checkpoint tree — opening, branching and exporting checkpoints.

Everything that does work here works for real: the tool catalog, the routing decision, reference-picture rounds, and recreating an uploaded picture — all driven by the same claw-gen CLI on the host machine. Open the workspace in ClawSCAD on the desktop for the rest.
